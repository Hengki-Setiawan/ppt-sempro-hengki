# PANDUAN DESAIN ANTI-BENTO: EDITORIAL & SPATIAL DECK

Dokumen ini adalah acuan visual untuk mengubah tampilan presentasi berbasis bento grid menjadi **Editorial Spatial Deck** kelas dunia.

---

## 1. Anatomi Perbandingan: Bento Box vs Editorial Spatial

| Elemen | Pendekatan Bento Kaku (Dilarang) | Pendekatan Editorial Spatial (Wajib) |
| :--- | :--- | :--- |
| **Tata Letak** | Kotak-kotak modular simetris bersebelahan (2x2 atau 3x1) | Asimetris dinamis; teks utama memimpin, visual 3D berinteraksi langsung dengan ruang kosong |
| **Tipografi** | Ukuran font seragam (14px - 18px) di dalam setiap kotak | Kontras skala dramatis: Headline 48px–56px bold, subhead 20px, metadata 11px monospaced |
| **Pembatas Area** | Border tebal mengelilingi setiap kelompok teks | Spacing alami, garis aksen horizontal/vertikal ultra-tipis (0.5px), atau subtle radial ambient glow |
| **Integrasi 3D** | Objek 3D ditaruh kaku di satu kotak terisolasi | Kanvas 3D menyatu secara mulus dengan latar belakang panggung (*full-bleed canvas*) |
| **Fokus Audiens** | Mata terpecah ke beberapa kotak sekaligus | Alur pandang terarah: Judul $\rightarrow$ Angka Kunci $\rightarrow$ Model 3D / Diagram |

## 2. 4 Pola Tata Letak Editorial Pengganti Bento

### Pola A: The Hero Metric & Single Narrative (Cocok untuk Slide Masalah/Urgensi)
- **Kiri (60% lebar):** 
  - Tag Kategori kecil di atas (Caps, letter-spacing +1.5px).
  - Headline pernyataan masalah yang kuat (*Action Title*).
  - Satu angka statistik masif (misal: **4,81%** Konversi Riil Toko).
  - 2–3 kalimat narasi konklusif yang menjelaskan makna angka tersebut.
- **Kanan (40% lebar):**
  - Model 3D kaos fisik atau diagram alur resolusi tinggi yang terhubung secara visual tanpa sekat kotak.

### Pola B: The Comparative Split (Cocok untuk Alur WA Manual vs Alur 3D)
- Dua zona kontras berdampingan:
  - **Sisi Kiri (Status Quo 2D):** Aksen warna muted slate/rose, merinci inefisiensi alur chat WhatsApp lama (14–25 pesan, 2–3 hari).
  - **Sisi Kanan (Solusi 3D WebGL):** Aksen cyan/cobalt berpendar, memperlihatkan alur otomatis instan (konfigurator 3D, kalkulasi biaya otomatis, checkout D2C).
- Di tengah terdapat garis pemisah tipis dengan ikon pembanding elegan.

### Pola C: The Architectural Blueprint (Cocok untuk Metodologi & Arsitektur Sistem)
- Teks pengantar ringkas di sisi atas/kiri.
- Diagram metodologi Prototyping 5 Tahap atau Arsitektur 6 Modul ditampilkan bersih (*clean blueprint*) tanpa kotak deskripsi melayang di dalam gambar.
- Teks penjelasan disajikan dalam ritme horizontal linear dengan penomoran elegan (`01`, `02`, `03`).

### Pola D: The Live Stage Showcase (Khusus Slide Demo Produk)
- Model 3D kaos meluncur ke tengah panggung sebagai aktor utama.
- Kontrol interaktif diletakkan di bagian bawah secara melayang (*floating pill dock*):
  - Palet warna (Hitam, Putih, Navy, Maroon, Sage).
  - Tombol sudut pandang (Depan, Belakang, Kerah/Sablon).
  - Status orbit 360° yang memberi tahu dosen bahwa mereka dapat memutar model secara bebas.
